# Практическая работа №10: Основы Vue.js

**Цель:** Освоить базовые принципы работы с Vue.js.

## Задачи
1. Подключение Vue.js через CDN.
2. Вывод данных с реактивностью.
3. Обработка событий (`@click`).
4. Двусторонняя привязка (`v-model`).
5. Работа с циклами (`v-for`).
6. Условный рендеринг (`v-if`).

## Как запустить
Откройте `index.html` в браузере или посмотрите на GitHub Pages: [ссылка](#) (после настройки).
